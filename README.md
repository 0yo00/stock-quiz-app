# 🎯 台股盤中刷題練習（MVP）

看歷史 K 線 + Pivot 七條線，預測收盤走勢的訓練工具。

---

## 快速啟動

### 方法 A：雙擊 `run.bat`（推薦）
1. 在資料夾內**雙擊 `run.bat`**
2. 第一次會自動裝依賴（streamlit、yfinance、plotly）
3. 瀏覽器自動打開 http://localhost:8502

### 方法 B：手動指令
```bash
cd C:\Users\jacky\Desktop\stock-quiz-app
pip install -r requirements.txt
streamlit run stock_quiz.py --server.port 8502
```

## 玩法

每一題 4 個隨機要素：

| 要素 | 範圍 |
|---|---|
| **股票** | 30 檔台股大型股（台積電、聯電、鴻海、聯發科…） |
| **日期** | 近 60 天內隨機某個交易日 |
| **揭露時間** | 10:00、11:00、12:00 三選一 |
| **Pivot 七條** | 用前一日 H/L/C 算（古典派） |

### 你會看到
- 該日 **9:00 至揭露時間** 的 5 分 K 線
- **R3 / R2 / R1 / P / S1 / S2 / S3** 七條 Pivot 水平線（疊在 K 線上）
- 前一日的 H/L/C 基礎資料

### 你要決定
從**揭露時間的價位** → **13:30 收盤價**，會「**漲**」還是「**跌**」？

兩個按鈕：📈 看漲 / 📉 看跌

### 計分規則

| 結果 | 分數 |
|---|---|
| 答對 | **+10 分** |
| 答錯 | **-5 分** |
| 連勝 3+ 加碼 | **每題額外 +5** |

平盤（變動 < 0.2%）會自動重抽，不算進題庫。

## 介面說明

- **上方**：總分、答題數、勝率、目前連勝、最高連勝
- **中間**：K 線圖 + Pivot（答題前只露揭露時間前的）
- **下方**：兩個答題按鈕 → 答完後揭曉完整 K 線 + 結果
- **側邊欄**：最近 10 題紀錄、清空分數按鈕

## 已知限制

| 項目 | 說明 |
|---|---|
| 歷史深度 | 5 分 K 只有近 60 天（yfinance 免費版限制） |
| 個股池 | 預設 30 檔大型股（如要改，編輯 `stock_quiz.py` 的 `DEFAULT_STOCKS`） |
| Pivot 精度 | 用前一日「日 K」資料算，與券商看盤軟體一致 |
